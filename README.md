## Project Title

**Student Tasks Management System**

## Project Description

A responsive web-based system developed to help students manage tasks, assignments, and deadlines efficiently through a simple dashboard interface.


## Features Included

* Login and Logout System
* Dashboard with task summary cards
* Pie chart for task status overview
* Task management page
* Assignment management page
* Responsive navigation menu
* Mobile-friendly responsive design - android and ios checked

## Frameworks / Libraries Used

* Bootstrap 5
* Chart.js
* Font Awesome
* Simple Datatables
* HTML5
* CSS3
* JavaScript
